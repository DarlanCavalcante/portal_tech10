# 🧠 Memory Bank — Portal Tech10

Banco de memória compacto para **agentes de IA** (Claude Code) e humanos. Objetivo: nas próximas sessões, o agente lê **apenas estes arquivos** para entender o estado do projeto — sem reanalisar o código. Abra esta pasta como **vault do Obsidian**; as notas usam `[[wikilinks]]` e um índice ([[MOC]]).

## Protocolo para o agente (ordem de leitura)
1. **Sempre comece por [[MOC]]** (índice).
2. Para "onde estamos agora", leia [[07-active-context]] e [[08-progress]].
3. Só mergulhe no código quando a tarefa exigir detalhe que a memória não cobre.

## Protocolo de atualização (fim de sessão)
Atualize [[07-active-context]], [[08-progress]] e faça append em [[09-decisions]]. Notas curtas e factuais; datas absolutas; toda afirmação verificável no repo.
